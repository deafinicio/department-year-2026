## Публікація

GitHub Actions перевіряє файли й публікує `site/` після зміни `main`. GitHub Pages використовує Source → GitHub Actions. Зовнішня збірка або backend не потрібні.

## Одинадцять елементів

Команда; підготовка; інформаційні сесії; географія; картографування даних; робота з громадами; матеріали та інструменти; Цифровий освітній простір; партнерство; ключові історії; статистика року.

Кожен 3D-об’єкт відкриває анімовану історію. У команді 13 індивідуальних профілів, фільтри складу й хронологія. Географія відкриває темну MapLibre-мапу Харкова, Берестина, Лозової та Ізюма з перельотами камери і картками. Окремий елемент розповідає про Mine Risk Map і дозволяє за запитом відкрити живий інструмент усередині презентації або окремою вкладкою.

Команда: 8 людей у базовому складі; двоє завершили діяльність у серпні–вересні; п’ятеро приєдналися в жовтні. Після змін — 11 людей. Іменний перелік координатора має пріоритет над попередніми агрегованими цифрами.

Цифровий освітній простір представлений на стадії закупівлі. Використано візуалізацію з наданої концепції. Статистичні значення порожні до внесення звітних даних; синтетичні числа видалені.

## Редагування

- `site/story.js` — факти, команда, екрани, координати міст, дані статистики.
- `site/scene.js` — платформа, 3D-об’єкти, вибір портретів і мапових позначок.
- `site/inspector.js` — історії, профілі, відкриття живого інструменту.
- `site/geo-map.js` — MapLibre, міста, рух камери, очищення ресурсів і резервні картки.
- `site/charts.js` — порожній стан статистики та графіки для подальшого наповнення.
- `site/app.js` — кроки, каталог, автопоказ і навігація.
- `site/assets/` — тематичні ілюстрації, іменні аватари, візуалізація студії, географічні дані.
- `docs/CONTENT.md` — джерела та наступні матеріали для наповнення.

## Залежності

Локально збережені Three.js 0.180.0, MapLibre GL JS 5.6.2 і варіативний Rubik з кирилицею; ліцензії у `site/vendor/`. Бібліотека мапи завантажується лише при відкритті географії. Для фонової карти використовується OpenFreeMap Dark: векторні тайли OpenMapTiles на основі OpenStreetMap, без API-ключа. Локальна копія стилю — `site/assets/basemap-dark.json`; ліцензії стилю — у `site/vendor/`. Авторство зберігається через джерело карти. Контур області й картки міст залишаються доступними без тайлів. Живий Mine Risk Map потребує інтернету й завантажується лише після натискання.

## Перевірка і запуск

```bash
python3 scripts/check-site.py
node scripts/check-content.mjs
python3 -m http.server 8080 --directory site
```

Для 3D-сцени та інтерактивної мапи потрібен WebGL 2. Історії доступні також через HTML-кнопки й каталог. Вимкнення анімації враховується під час зміни камери та відкриття екранів.
