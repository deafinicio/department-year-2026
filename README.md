# Ми складаємо рік · 2026

Інтерактивна річна презентація відділу протимінної діяльності: велика 3D-платформа, темна неонова тема, десять складових року, історії, профілі команди та інтерактивні діаграми.

## GitHub Pages

Адреса після ввімкнення й успішного розгортання:

https://deafinicio.github.io/department-year-2026/

Одноразове налаштування: **Settings → Pages → Build and deployment → Source → GitHub Actions**.

Workflow `.github/workflows/pages.yml` перевіряє файли та публікує каталог `site/` після кожної зміни гілки `main`. Якщо перший запуск стався до ввімкнення Pages, після налаштування запустіть workflow повторно у вкладці **Actions**.

## Десять елементів

Команда; підготовка; інформаційні сесії; географія; робота з громадами; матеріали та інструменти; Цифровий освітній простір; партнерство; ключові історії; статистика року.

Кожен об’єкт відкриває анімовану історію з кількох екранів. Кожен портрет команди має власний профіль. Каталог дозволяє вибрати будь-який уже доданий елемент через HTML-інтерфейс. Автопоказ зупиняється під час відкриття історії, ручного переходу або приховування вкладки.

Статистика містить фільтри кварталу, перемикання сесій/участей і лінії/стовпчиків, інтерактивні точки, діаграму форматів, вікові групи та таблицю даних.

## Редагування

- `site/story.js` — команда, розділи, тексти, ракурси, демодані.
- `site/scene.js` — 3D-сцена та вибір об’єктів.
- `site/inspector.js` — екрани історій і профілі людей.
- `site/charts.js` — інтерактивні діаграми.
- `site/app.js` — навігація й керування показом.
- `site/assets/` — зображення.

Зображення ілюстративні. Склад команди оновлено за даними координатора: базово 6 інструкторів і координатор; 2 інструктори завершили роботу у серпні–вересні, 5 приєдналися у вересні–листопаді. Після цих змін — 9 інструкторів і координатор; за описаний період — 12 різних людей. Імена інструкторів ще не додані. Статистика синтетична та не описує діяльність відділу. Мапа умовна. Реальні фотографії, персональні матеріали та звітна статистика ще не додані. До історій внесено окремий екран про участь Відділу в Regional Summer Camp 2026 для молоді; детальна програма та фотографії очікують наповнення. Участі не слід автоматично називати унікальними людьми.

## Локальний запуск

```bash
python3 -m http.server 8080 --directory site
```

Відкрити http://localhost:8080. Потрібен браузер з WebGL 2. Усі залежності локальні, CDN під час показу не використовується. Three.js 0.180.0; ліцензія: `site/vendor/LICENSE-three.txt`.

## Перевірка

```bash
python3 scripts/check-site.py
```

Під час розробки також перевірені десять послідовних шарів, попадання променя у постаменти/портрети/позначки мапи, DOM-взаємодії історій та статистики, суми за кварталами, каталог, перезапуск і пауза автопоказу. GPU-рендеринг у середовищі розробки недоступний.
